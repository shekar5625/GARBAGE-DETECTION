#   api.py   -> Flask REST API (port 5000)
#   main.py  -> RTSP capture + YOLOv5 inference loop
#
# ----------------------------------------------------------------------
# IMPORTANT — install torch FIRST on a CPU-only machine:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements.txt
#
# Reason: `ultralytics` (required below) declares torch as a dependency.
# If torch is not already present, pip resolves it from PyPI and pulls the
# CUDA build — ~2.5 GB of GPU libraries that will never be used on a
# machine with no NVIDIA card. Installing the CPU wheel first makes the
# requirement already-satisfied, so nothing CUDA is downloaded.
#
# See DEPLOY.md for the full field-deployment checklist.
# ----------------------------------------------------------------------
