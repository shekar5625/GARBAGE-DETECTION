Part B

Live inference

The main loop in Backend/main.py. A cheap motion check decides when the model runs, so the CPU stays mostly idle.

flowchart TD
  subgraph CAP["1 · Capture"]
    CAM["Hikvision camera
channel 101 · main stream"] --> RTSP["RTSP over TCP · OpenCV FFMPEG
buffer size 1"]
    RTSP --> TH["FreshestFrame thread
keeps latest frame only"]
    TH --> OK{"frame read OK?"}
    OK -- no --> RC["release · wait 2 s · reconnect"] --> RTSP
    OK -- yes --> FR["Full-res BGR frame"]
  end

  subgraph GATE["2 · Motion gate"]
    FR --> ROI["Crop to ROI
(drawn with r · optional roi.json)"]
    ROI --> MOG["MOG2 background subtraction
history 500 · varThreshold 25 · shadows on"]
    MOG --> BIN["threshold 200 (drops shadows)
morph open → dilate ×2"]
    BIN --> CNT["count moving pixels"]
    CNT --> RUN{"(motion above threshold AND ≥ 5 s since last)
OR (known piles AND ≥ 30 s)?"}
    RUN -- no --> SHOW["draw HUD · show frame"] --> FR
  end

  subgraph DET["3 · YOLOv5 inference"]
    RUN -- yes --> CLEAN["copy clean ROI crop
before HUD is drawn"]
    CLEAN --> RGB["BGR → RGB · PIL image"]
    RGB --> PRE["AutoShape: letterbox to 640
scale pixels to 0–1"]
    PRE --> NET["YOLOv5n forward pass
best1000.pt on CPU"]
    NET --> NMS["NMS · conf ≥ 0.50 · IoU 0.45"]
    NMS --> BOX["boxes: xyxy · confidence · class"]
    BOX --> OFF["shift by ROI offset
→ full-frame coordinates"]
  end

  subgraph TRK["4 · Pile tracker"]
    OFF --> MATCH{"matches a known pile?
IoU ≥ 0.3 OR centre inside"}
    MATCH -- yes --> UPD["update box · misses = 0"]
    MATCH -- no --> NEW["new pile → add to list"]
    UPD --> MISS["unmatched known piles: misses + 1
misses ≥ 3 → forget (cleared)"]
    NEW --> MISS
    MISS --> ANY{"any new piles?"}
    ANY -- no --> SHOW
  end

  subgraph OUT["5 · Report"]
    ANY -- yes --> DRAW["draw boxes on clean full frame"]
    DRAW --> SAVE["save detections/garbage_timestamp.jpg"]
    SAVE --> POST["background thread
POST /add/area/mac (Flask)"]
    POST --> DB["SQLite yolo row · is_verified = 0
→ Pending on dashboard"]
    SAVE --> SND["audio alert (pygame)"]
  end
